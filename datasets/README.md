# Datasets

Commit only small datasets (under a few MB). Large files are git-ignored; download them with the links below
or with `keras.datasets` / `sklearn.datasets`.

| Dataset | Used in | Source |
|---|---|---|
| Iris, Breast Cancer, Digits | Weeks 8–10 | `sklearn.datasets` |
| MNIST | Weeks 9, 23 | `keras.datasets.mnist` |
| CIFAR-10 | Week 23 | `keras.datasets.cifar10` |
| Imagenette (optional) | Week 23 | https://github.com/fastai/imagenette |
| Kaggle datasets | Projects | https://www.kaggle.com/datasets |
